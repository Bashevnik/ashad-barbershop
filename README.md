# ashad-barbershop

Сайт барбершопу **ASHAD** (Дніпро, дві зали). Чистий HTML/CSS/JS, без фреймворків
і без CDN — усі бібліотеки та шрифти лежать локально.

```
index.html        Головна
posluhy.html      Послуги і ціни
atmosfera.html    Атмосфера (інтер'єри, роботи, відео)
kontakty.html     Контакти

css/style.css     уся верстка
css/fonts.css     @font-face (згенеровано)
fonts/            Bitter, Golos Text, Kelly Slab — woff2, кирилиця
js/app.js         завіса переходів, меню, стрічка відео, поява блоків
js/lib/           gsap, ScrollTrigger, lax — локальні копії
assets/           фото і відео (див. assets/README.md)
build-pages.js    генератор чотирьох сторінок: node build-pages.js
```

Сторінки — звичайна статика, їх можна правити руками. Але контент, який
повторюється (шапка, підвал, прайс, адреси, Schema.org), зібраний у
`build-pages.js` — зручніше змінити там і перегенерувати:

```
node build-pages.js
```

## Що з чого зроблено

Кольори зняті з фотографій залів: тепла штукатурка як тло, зелений оксамит
честерфілда як головний акцент (єдине, що є в обох залах), цегляний рудий і
жовтий від ламп — малими дозами, чорний тільки в тексті.

Фірмовий знак — власний SVG: кільце лампочок із круглої вивіски плюс кашкет.
`assets/logo.png` використовується лише як favicon.

Шрифти: Bitter (брусковий, заголовки), Golos Text (текст), Kelly Slab
(вивісочні дрібниці — ціни, назва в шапці). Повна кирилиця з українськими
літерами.

## Технічні дрібниці

- Завіса між сторінками намальована в розмітці й видима з першого кадру,
  наступна сторінка префетчиться на `mouseover`/`touchstart`.
- Без JS завіса не показується взагалі (`html.no-js`), сайт повністю читається.
- `prefers-reduced-motion` вимикає анімації появи, обертання знака і затримки.
- Відео: `src` підставляється при наближенні картки, грає тільки видиме,
  стрічка тягнеться мишею і крутиться колесом, зупиняється по `scroll-snap`.
- SEO: свої title/description на кожній сторінці, Open Graph, `sitemap.xml`,
  `robots.txt`, JSON-LD `HairSalon` з двома адресами і графіком.

Перевірено в Chrome на 1440×900 і 390×844.
